# Integração com o Supabase Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ligar projetos de sistema a projetos do Supabase, mostrar o estado (no ar/pausado) e avisar quando um estiver pausado.

**Architecture:** Espelha a integração do Figma: token em `config`, cliente com `fetch` injetável (`server/supabase/cliente.js`), serviço com cache de 5 min (`server/supabase/servico.js`), rotas (`server/routes/supabase.js`), cartão no projeto e alertas na faixa "Pede atenção".

**Tech Stack:** Express, node:sqlite, React, vitest. `npx vitest run` na raiz; fetch falso `githubFalso(rotas)` em `server/test/githubFalso.js`; cache `criarCache(ttlMs)` de `server/github/cache.js`; modelos prontos: `server/figma/*`, `server/routes/figma.js`, `web/src/pages/config/ConexaoFigma.jsx`, `web/src/pages/projeto/CartaoFigma.jsx`, `web/src/pages/servicos/atencaoSites.js` (alertas do GitHub entram por `githubAlertas`).

**Spec:** docs/superpowers/specs/2026-11-26-supabase-design.md

## Global Constraints
- API: `https://api.supabase.com/v1/projects`, cabeçalho `Authorization: Bearer TOKEN`; cada item traz `id` (ref), `name`, `region`, `status`, `created_at`.
- Estados: `ACTIVE_HEALTHY` → `no_ar`; `INACTIVE`, `PAUSING` → `pausado`; `COMING_UP`, `RESTORING` → `subindo`; qualquer outro → `outro`.
- Erros: 401/403 "Token do Supabase inválido ou sem permissão. Cole um novo em Configurações → Supabase."; rede "Não foi possível falar com o Supabase. Verifique a internet."; sem token 409 "Conecte o Supabase em Configurações."; repetido 400 "Esse projeto do Supabase já está ligado a outro projeto".
- Só leitura: nenhum POST/PATCH/DELETE ao Supabase. `supabase_token` fora do backup. Arquivos CRLF; UI em português.

## Review Focus
- Supabase fora do ar ou token revogado não derruba a página do projeto nem a faixa "Pede atenção" (Tasks 3 e 4).
- Projeto ligado que sumiu da conta Supabase → `encontrado:false`, sem erro (Task 2).
- Lista com mais de uma página/muitos projetos continua funcionando (a API devolve tudo de uma vez; o teste usa 30 itens).
