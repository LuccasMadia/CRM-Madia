# Integração com o GitHub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ligar o CRM ao GitHub: auditoria de repositórios x projetos, criação automática de repositório privado, gráfico de commits e alertas de visibilidade.

**Architecture:** Cliente `fetch` injetável para `api.github.com` (padrão de `server/hospedagem/vercel.js`), função pura de auditoria que cruza repositórios com projetos, rotas Express em `server/routes/github.js` com cache em memória de 10 minutos, e telas React nas Configurações, na página do projeto e na visão GitHub de Serviços. Nada de GitHub é gravado além de `projetos.github_repo` e do token em `config`.

**Tech Stack:** Node 24 (node:sqlite), Express 5, React 19, vitest + supertest + testing-library. Sem dependência nova.

**Spec:** `docs/superpowers/specs/2026-11-24-github-design.md`

## Global Constraints

- Sem dependência nova; só `fetch` (injetável nos testes, como o Vercel).
- Token em `config.github_token`; nunca devolvido pela API; entra na limpeza de `server/routes/backup.js` junto de `vercel_token` e `instagram_token`.
- O CRM cria repositório **sempre privado** e nunca altera visibilidade (só lê e avisa).
- Repositório público de projeto **real** só alerta quando o projeto está em `entregue`; de projeto `privado` interno alerta em qualquer etapa; de projeto fictício nunca alerta.
- Cache de 10 minutos em memória para lista de repositórios e commits, com `?atualizar=1` para forçar.
- Interface em português, tema escuro, responsivo; testes de web rodam da raiz (`npx vitest run`), arquivos são CRLF.
- Falha do GitHub nunca impede salvar um projeto.
- Etapas: ideia, prototipo, apresentado, valor_definido, andamento (Versão final), teste, entregue, perdido.

## Review Focus

- Token inválido ou sem permissão: rota devolve 502 com mensagem em português e o projeto continua intacto.
- GitHub sem resposta de estatísticas (HTTP 202 "calculando"): o gráfico mostra "calculando", não erro.
- Dois projetos com o mesmo título: o segundo repositório recebe sufixo (`-2`), não falha nem duplica.
- Projeto que sai de Entregue deixa de alertar como público.
- Repositório que existe no GitHub mas foi apagado: o vínculo mostra "repositório não encontrado" em vez de quebrar a página.
