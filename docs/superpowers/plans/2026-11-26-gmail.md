# Integração com o Gmail Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mostrar, na página do cliente, as últimas conversas de e-mail com ele (somente leitura).

**Architecture:** OAuth do Google com escopo `gmail.readonly`, fluxo local (redirecionamento para `127.0.0.1:5174`). Refresh token em `config`; e-mails buscados ao vivo na API do Gmail, cache de 5 min, nada gravado no banco. Cliente `fetch` injetável (`server/gmail/cliente.js`), serviço (`server/gmail/servico.js`), rotas (`server/routes/gmail.js`), cartão na página do cliente.

**Tech Stack:** Express, node:sqlite, React, vitest, sem dependência nova. `npx vitest run` na raiz; fetch falso `githubFalso(rotas)` de `server/test/githubFalso.js`; cache `criarCache` de `server/github/cache.js`; modelos: `server/figma/*`, `server/routes/figma.js`, `web/src/pages/config/ConexaoFigma.jsx`.

**Spec:** docs/superpowers/specs/2026-11-26-gmail-design.md

## Global Constraints
- Endpoints do Google: autorização `https://accounts.google.com/o/oauth2/v2/auth` (`response_type=code`, `access_type=offline`, `prompt=consent`, `scope=https://www.googleapis.com/auth/gmail.readonly`, `redirect_uri=http://127.0.0.1:5174/api/gmail/callback`, `state`); troca de código/refresh em `POST https://oauth2.googleapis.com/token`; revogação `POST https://oauth2.googleapis.com/revoke`; API `https://gmail.googleapis.com/gmail/v1/users/me/...` (`profile`, `threads?q=&maxResults=10`, `threads/ID?format=metadata&metadataHeaders=Subject&metadataHeaders=From&metadataHeaders=Date`).
- Segredos (`gmail_client_id`, `gmail_client_secret`, `gmail_refresh_token`, `gmail_usuario`) em `config`, fora do backup e fora de `GET /config` e de qualquer resposta da API; o `access_token` só vive em memória.
- Erros: sem conexão 409 "Conecte o Gmail em Configurações."; token revogado/expirado (`invalid_grant` ou 401) → 502 "Gmail desconectado. Conecte de novo em Configurações → Gmail."; rede "Não foi possível falar com o Google. Verifique a internet."
- `state` do OAuth: aleatório, de uso único, validade de 10 min, guardado em memória; callback com `state` desconhecido → 400.
- Somente leitura: nenhum envio, nenhuma alteração de e-mail. Arquivos CRLF; UI em português.

## Review Focus
- Callback com `state` errado ou repetido é recusado e nada é salvo (Task 2).
- Cliente sem e-mail ou e-mail com caracteres especiais (`+`, aspas) não quebra a busca nem permite injetar operadores do Gmail (Task 2).
- Refresh token revogado: o cartão mostra o chamado para reconectar e o resto da página do cliente continua (Task 3).
- O texto do passo a passo avisa do modo "Teste" (token expira em 7 dias) e manda publicar como "Em produção" (Task 3).
