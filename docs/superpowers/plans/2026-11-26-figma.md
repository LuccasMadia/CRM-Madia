# Integração com o Figma Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ligar cada projeto de site/sistema a um arquivo do Figma e mostrar link + data da última edição.

**Architecture:** Token pessoal em `config` + API REST do Figma, no molde do GitHub: cliente com `fetch` injetável (`server/figma/cliente.js`), serviço com cache de 10 min (`server/figma/servico.js`), rotas (`server/routes/figma.js`), cartão na aba Geral do projeto.

**Tech Stack:** Express, node:sqlite, React, vitest. Testes: `npx vitest run` na raiz; fetch falso em `server/test/githubFalso.js` (`githubFalso(rotas)` → `{fetch, requisicoes}`, rotas `"METODO url"` ou url, valor = corpo | `{status, corpo, headers}` | fn); `server/github/cache.js` (`criarCache(ttlMs)`, `obter(chave, produzir, {forcar})`, `limpar`) é reaproveitado.

**Spec:** docs/superpowers/specs/2026-11-26-figma-design.md

## Global Constraints
- Header da API do Figma: `X-Figma-Token`; base `https://api.figma.com/v1`.
- Erros: 401/403 → "Token do Figma inválido ou sem permissão. Cole um novo em Configurações → Figma."; rede → "Não foi possível falar com o Figma. Verifique a internet."; 404 → "Arquivo do Figma não encontrado."
- Link inválido → 400 "Cole o link de um arquivo do Figma"; arquivo repetido → 400 "Esse arquivo já está ligado a outro projeto"; sem token → 409 "Conecte o Figma em Configurações.".
- Token e usuário (`figma_token`, `figma_usuario`) nunca vão no backup.
- Arquivos do repo são CRLF; textos da UI em português.

## Review Focus
- Link com query (`?node-id=1-2`), barra final ou `/file/` em vez de `/design/` ainda extrai o código certo (Task 1).
- Figma fora do ar / token revogado não derruba a página do projeto: o cartão mostra o erro e o link continua (Task 3).
- Remover a ligação com `figma_url: ''` limpa o campo e libera o arquivo para outro projeto (Task 1).
